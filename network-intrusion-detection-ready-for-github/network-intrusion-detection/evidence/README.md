# Project Evidence Checklist

Add the following evidence after checking that each file contains no private data, access tokens, or sensitive information:

- [ ] Original Colab notebook (`.ipynb`) with code and executed outputs.
- [ ] Class distribution figure.
- [ ] Model comparison figure.
- [ ] XGBoost confusion matrix.
- [ ] XGBoost feature importance figure.
- [ ] Final report PDF.
- [ ] Dataset source/citation and license details.
- [ ] Short author contribution statement.
- [ ] Optional screenshots of key notebook sections, with dates/context where useful.

Evidence should be genuine artifacts from the actual project. Do not fabricate screenshots, timestamps, experiment logs, or authorship claims.
